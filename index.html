타임모아 개인정보 처리방침

시행일: 2026-08-13 (최초 시행 2026-07-03)

타임모아(이하 "앱")는 사용자의 개인정보를 소중하게 생각합니다.
이 문서는 앱이 어떤 정보를 다루는지 설명합니다.

요약

타임모아는 기본적으로 어떠한 개인정보도 수집하지 않습니다.
리그에 참여하는 경우에만, 아래 세 가지가 서버에 저장됩니다.

  • 닉네임 (직접 정한 별명, 실명이 아니어도 됩니다)
  • 이번 주 집중 시간 합계 (초 단위 숫자 하나)
  • 익명 기기 식별 정보 (Apple App Attest 기반, 실명·연락처와 연결되지 않음)

계정과 로그인은 여전히 없습니다. 리그에서 나가고 데이터 삭제를 요청하면 (프로필 > 리그 데이터 삭제) 서버에서 즉시 완전 삭제됩니다. 분석(애널리틱스) 도구는 사용하지 않습니다. 휴식 화면에 한해 광고가 표시되며, 자세한 내용은 아래 "광고" 항목을 참고해 주세요.

기기에만 저장되는 데이터

앱이 동작하기 위해 아래 데이터를 사용자의 기기 안에만 저장합니다.

데이터용도저장 위치
목표 정보 (이름, 가치, 기간, 하루 목표 시간)시간당 가치 계산기기 내
타이머 세션 기록 (집중/휴식 시간, 적립/차감 금액)금고 잔액·스트릭·차트 표시기기 내
알림 설정 (종류별 on/off, 리마인더 시각)로컬 알림 예약기기 내

이 데이터는 개발자를 포함한 누구에게도 전송되지 않으며, 앱을 삭제하면 함께 삭제됩니다.

리그 데이터

리그(친구와 집중 시간을 겨루는 기능)에 참여하는 경우에만, 아래 데이터가 서버에 저장됩니다.

데이터용도보관
닉네임리그 순위표 표시삭제 요청 시 즉시, 미접속 180일 후 자동 삭제
주간 집중 시간 합계리그 순위 계산동일
익명 기기 증명부정 참여 방지동일

리그 서버는 Cloudflare(아시아 태평양 리전)에서 운영되며, 전송은 HTTPS로 암호화됩니다. 만 14세 미만은 리그에 참여할 수 없습니다.

광고

앱은 휴식 타이머 화면에만 Google AdMob 배너 광고를 표시합니다. 집중 타이머·홈·금고·리그 화면에는 광고가 없습니다.

  • 광고는 비맞춤(non-personalized)으로만 제공됩니다. 맞춤 광고를 위한 추적을 하지 않으며, 앱 추적 투명성(ATT) 권한도 요청하지 않습니다.
  • 광고 표시 과정에서 Google Mobile Ads SDK가 기기 정보, IP 주소 기반의 대략적인 위치, 광고 성과·진단 데이터를 수집할 수 있습니다. 이는 광고 제공과 부정 방지 목적이며, 사용자 신원과 연결되지 않습니다.
  • Google의 데이터 처리에 관한 자세한 내용: Google 광고 정책

알림

앱의 모든 알림(시간 단위 적립, 목표 달성, 시작 리마인더, 리그 알림)은 기기에서 직접 예약되는 로컬 알림입니다. 푸시 서버를 사용하지 않습니다. 알림 권한은 iOS 설정에서 언제든지 변경할 수 있습니다.

금고 금액에 관하여

앱에 표시되는 모든 금액(시간당 가치, 금고 잔액, 적립/차감액)은 사용자가 설정한 목표의 가치를 시간으로 환산한 동기부여용 가상 수치입니다. 실제 화폐가 아니며, 충전·결제·송금·환전·환급 기능과 무관합니다.

아동의 개인정보

만 14세 미만은 리그에 참여할 수 없으며, 리그 외 기능은 어떤 개인정보도 수집하지 않습니다.

처리방침 변경

기능 추가(예: iCloud 백업)로 데이터 취급이 달라지는 경우, 이 문서를 갱신하고 앱 업데이트 노트로 알립니다.
